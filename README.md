# Trendora - Full Stack E-commerce App

A modern full-stack e-commerce application built with React, Express.js, and PostgreSQL.

## Features

- Product listing
- Search products
- Shopping cart
- Quantity management
- Remove items
- Clear cart
- Persistent cart with localStorage
- Responsive UI

## Tech Stack

- React
- Vite
- Express.js
- PostgreSQL
- Axios
- Context API

## Run Locally

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run dev
```
